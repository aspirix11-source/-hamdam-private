# Hamdam

A mobile-first private couples space with a soft cream and blush-pink design.

## Run locally
- Install Node.js 20+
- Run `npm install`
- Run `npm run dev`
- Open http://localhost:3000

## Prototype status
The current version is a UI prototype with local demo messages. Authentication, database persistence, realtime chat, private media storage, end-to-end encryption and calling are not yet implemented. Do not use it for sensitive conversations until those features and access policies are built and tested.
